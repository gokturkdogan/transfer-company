# SEO

## Brand

Public brand name: **Royal Rhein Transfers** (`common.appName` in `messages/*.json`, `APP_NAME` in `src/config/constants.ts`).

## Sitemap

- Generated by `src/app/sitemap.ts` (async)
- Static paths: `/`, `/about`, `/booking`, `/fleet`, `/blog`, `/privacy`
- Blog hub `/blog` and articles `/blog/{slug}` from `getAllBlogSlugs()` in `src/content/blog/registry.ts`
- Dynamic fleet detail paths: `/fleet/{code}` from `getCachedActiveVehicleCodes()` (lowercase slugs)
- Destination transfer landings: `/transfers/{code}` from `getCachedPopularDestinations(DEFAULT_LOCALE)` (lowercase codes)
- Locale list from `getCachedEnabledLocales()` with `x-default` via `buildLanguageAlternates`

## Destination landings

- Route: `/[locale]/transfers/[districtSlug]` (`revalidate = 120`)
- Resolves active district by lowercase `code`
- Metadata via `buildPageMetadata`; copy under `transfers.district` in `messages/*.json`
- Primary CTA deep-links to `/booking` with airport + district prefilled
- Homepage popular destinations deep-link to `/booking?district={id}` with district prefilled

## Blog / transfer guides

- Hub: `/[locale]/blog` — header nav **Rehberlerimiz** (`home.nav.guides`) + footer **Transfer Rehberi** column
- Articles: `/[locale]/blog/[slug]` — content in `src/content/blog/posts/*` (tr + en; other locales fall back to en)
- Footer column **Transfer Rehberi** links hub + featured articles
- ISR `revalidate = 120` on hub and article pages

## Hreflang / language alternates

- Use `buildLanguageAlternates()` / `buildPageMetadata()` from `src/lib/seo/metadata.ts`
- Alternates cover **enabled site locales** (from `resolveSiteLocales` / `getCachedEnabledLocales`), not a hard-coded full `LOCALES` list when admin has disabled a locale
- Always include `x-default` pointing to `/{DEFAULT_LOCALE}{path}` (default locale is `tr`)
- Canonical URLs keep the locale prefix (`localePrefix: "always"`)

## JSON-LD

- Homepage structured data lives in `src/components/seo/HomeJsonLd.tsx`
- Allowed: Organization / TravelAgency identity, WebSite, Service, FAQPage derived from real page content
- **Forbidden:** fabricated `AggregateRating`, fake review counts, or any schema claims that are not backed by real data
- Brand name in JSON-LD must come from `common.appName` (Royal Rhein Transfers)

## Metadata helpers

```ts
import {
  buildLanguageAlternates,
  buildPageMetadata,
} from "@/lib/seo/metadata";
```

- `buildPageMetadata` sets title, description, canonical, hreflang, Open Graph, Twitter, and robots
- Page titles use `buildPageTitle()` to append `APP_NAME` (`Royal Rhein Transfers`) once, with `absolute` metadata to avoid layout template duplication
- Base URL comes from `clientEnv.NEXT_PUBLIC_APP_URL`
- Prefer these helpers on public marketing pages for consistent hreflang behavior
