# SEO

## Brand

Public brand name: **Royal Rhein Transfers** (`common.appName` in `messages/*.json`, `APP_NAME` in `src/config/constants.ts`).

## Sitemap

- Generated by `src/app/sitemap.ts` (`revalidate = 120`) via `getPublicSitemapEntries()` in `src/lib/seo/public-sitemap-routes.ts`
- Static paths: `/`, `/about`, `/booking`, `/fleet`, `/blog`, `/privacy`
- Blog hub `/blog` and articles `/blog/{slug}` from `getCachedBlogSlugs()` (active guides in `blog_posts`)
- Blog article URLs are emitted only for locales that have stored translations (not fallback-only variants)
- Dynamic fleet detail paths: `/fleet/{code}` from `getCachedActiveVehicleCodes()` (lowercase slugs)
- Locale list from `getCachedEnabledLocales()` with `x-default` via `buildLanguageAlternates`
- **No** `/transfers/{code}` URLs — destination landings were removed; homepage popular destinations and guide CTAs deep-link to `/booking?district={id}`

## Admin guide publish / sitemap refresh

- `revalidateBlog()` in `src/features/admin/server/actions/guides.ts` revalidates:
  - `blog-posts` cache tag
  - `/blog` and `/blog/{slug}` paths
  - `/sitemap.xml`

## Blog / transfer guides

- Hub: `/[locale]/blog` — header nav **Rehberlerimiz** (`home.nav.guides`) + footer **Transfer Rehberi** column
- Articles: `/[locale]/blog/[slug]` — content in `blog_posts` / `blog_post_translations` (admin **Rehberler**); page copy uses fallback `tr` → `en` when a locale translation is missing
- Hreflang and sitemap alternates for articles use **published translation locales** only (`listPublishedLocalesForPost`)
- Footer column **Transfer Rehberi** links hub + featured articles
- Optional `transferDistrictCode` on a guide resolves to `/booking?district={id}` via `getBookingHrefForPost()`
- ISR `revalidate = 120` on hub and article pages
- `generateStaticParams` on layout, blog articles, and fleet detail uses `getCachedEnabledLocales()` × route params

## Hreflang / language alternates

- Use `buildLanguageAlternates()` / `buildPageMetadata()` from `src/lib/seo/metadata.ts`
- Alternates cover **enabled site locales** (from `resolveSiteLocales` / `getCachedEnabledLocales`), not a hard-coded full `LOCALES` list when admin has disabled a locale
- Blog articles further restrict alternates to locales with stored translations
- Always include `x-default` pointing to `/{DEFAULT_LOCALE}{path}` (default locale is `tr`)
- Canonical URLs keep the locale prefix (`localePrefix: "always"`)

## JSON-LD

- Homepage structured data: `src/components/seo/HomeJsonLd.tsx`
- Blog articles: `src/components/seo/BlogArticleJsonLd.tsx` (`Article` + `BreadcrumbList`)
- Allowed: Organization / TravelAgency identity, WebSite, Service, FAQPage, Article, BreadcrumbList derived from real page content
- **Forbidden:** fabricated `AggregateRating`, fake review counts, or any schema claims that are not backed by real data
- Brand name in JSON-LD must come from `common.appName` (Royal Rhein Transfers)

## Metadata helpers

```ts
import {
  buildLanguageAlternates,
  buildPageMetadata,
} from "@/lib/seo/metadata";
```

- `buildPageMetadata` sets title, description, canonical, hreflang, Open Graph, Twitter, and robots
- Page titles use `buildPageTitle()` to append `APP_NAME` (`Royal Rhein Transfers`) once, with `absolute` metadata to avoid layout template duplication
- Base URL comes from `clientEnv.NEXT_PUBLIC_APP_URL`
- Prefer these helpers on public marketing pages for consistent hreflang behavior

## Booking entry points (SEO)

- Homepage popular destinations: `/booking?district={districtId}`
- Guide sidebar district CTA: `/booking?district={districtId}` when `transferDistrictCode` resolves
- `/booking` remains in the sitemap for discovery; query params are not reflected in canonical URLs
